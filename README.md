# WorkPulse

Desktop work-health tracker for work sessions, breaks, hydration, eye breaks, and activity monitoring.

## Features
- Work session timer
- Automatic idle detection
- Automatic timer pause/resume
- Break tracking
- Water tracking
- Eye-break reminders
- Persistent history
- Daily activity tracking
- Today / Yesterday history
- Desktop GUI

## Run
``powershell
python -u main.py
``n

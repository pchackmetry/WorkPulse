\## Project Overview



WorkPulse is a Windows desktop application designed to track work sessions, breaks, hydration, eye breaks, and user inactivity.



\## Main Features



\- Work session timer

\- Automatic idle detection

\- Automatic timer pause and resume

\- Break tracking

\- Water tracking

\- Eye-break reminders

\- Persistent activity history

\- Daily activity tracking

\- Today and Yesterday activity display



\## Technology



\- Python

\- PySide6

\- JSON local storage

\- PyInstaller

\- Git

\- GitHub



\## Development



WorkPulse was developed as an independent software project and is maintained using Git version control.



The Windows executable is generated from the project source code using PyInstaller.
